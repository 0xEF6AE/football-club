# 축구 모임 웹

주말 축구 모임을 위한 작은 웹앱.

- **경기 결과** — 매주 경기 점수와 득점자를 기록하고 시즌 전적(승/무/패, 득실)을 한눈에 본다. 경기마다 킥오프 시간을 적어 두면 목록·카톡 텍스트·링크 미리보기에 함께 나오고, 경기 상세에는 그 상대와의 역대 전적("3전 2승 1패")이 붙는다.
- **선수별 기록** — 득점왕 표나 선수 목록에서 이름을 누르면 출전 수, 골, 도움, 참석률과 경기별 내역이 나온다. 출전은 참석 투표 "참석", 경기에 붙인 포메이션 명단, 골·도움 기록 중 하나라도 있으면 센다.
- **참석 투표** — 예정 경기에 참석/불참/보류로 답한다. 관리자가 마감 시각을 정하면 그 뒤로는 바꿀 수 없다. 투표 아래 댓글로 왜 불참·보류인지 남길 수 있다(이름 공개, 마감 뒤에도 가능). 다른 사람이 내 이름으로 누르지 못하게, 처음 투표할 때 정한 개인 PIN 4자리가 있어야 응답과 댓글을 바꿀 수 있다. PIN을 잊으면 관리자가 선수 목록의 열쇠 버튼으로 초기화한다.
- **익명 피드백** — 각 경기에 대해 좋았던 점, 아쉬운 점, 제안을 익명으로 남긴다. 작성자 정보는 어떤 형태로도 저장하지 않는다.
- **포메이션** — 선수마다 가능한 포지션을 등록해 두면, 참석자만 골라 1~4쿼터를 4-2-3-1 / 4-1-2-3 / 4-3-3 / 4-4-2 / 3-5-2로 자동 배치한다. 앞 쿼터에서 쉰 선수가 다음 쿼터에 먼저 들어가도록 출전 시간을 나눈다. 쿼터마다 자리를 눌러 바꾸고, 네 쿼터를 한 번에 저장하고, 카톡용 텍스트로 복사할 수 있다.

## 시작하기

```bash
npm install
npm run db:push   # local.db에 테이블 생성
npm run db:seed   # (선택) 예시 선수와 경기 넣기
npm run dev       # http://localhost:3000
```

## 배포

Vercel(함수 지역 도쿄 `hnd1`, `vercel.json`) + Turso(도쿄). Vercel 프로젝트 환경변수에 아래 값을 넣는다.

```
DATABASE_URL=libsql://...
DATABASE_AUTH_TOKEN=...
ADMIN_PASSCODE=...
NEXT_PUBLIC_CLUB_NAME=뽀잉 fc
```

DB 테이블은 로컬에서 반영한다. 같은 Turso 두 값을 `.env.turso`(git 제외)에 넣어 두고:

```bash
npm run db:push:turso   # 스키마를 바꿀 때마다. 로컬은 npm run db:push
```

2026-09-28 이전 스키마(포메이션이 `shape`/`assignments` 컬럼)로 만든 DB에 push하면 `quarters` 컬럼이 이름을 바꾼 것인지 묻는데, "create column"을 고른다. 이런 질문이 나오는 push는 대화형 터미널에서 실행해야 한다.
